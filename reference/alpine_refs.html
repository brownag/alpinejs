alpine_refsR Documentation

Reference a DOM element by its x-ref name

Description

Generates a ⁠$refs.name⁠ JavaScript expression for accessing a DOM element that was labeled with alpine_ref(). Use the resulting expression in event handlers, alpine_bind(), or alpine_init() to interact with the element.

Usage

alpine_refs(name)

Arguments

name

Character string. The reference name assigned via alpine_ref().

Details

⁠$refs⁠ is an object on every Alpine component that maps reference names to their DOM elements. You can call any standard DOM method on the result: ⁠$refs.name.value⁠, ⁠$refs.name.focus()⁠, ⁠$refs.name.scrollIntoView()⁠, etc.

Value

An htmlwidgets::JS object containing the ⁠$refs.name⁠ expression.

See Also

Other Magic Properties: alpine_dispatch(), alpine_el(), alpine_next_tick(), alpine_store_js(), alpine_watch()

Examples


htmltools::tagList(
  htmltools::tags$input(type = "text") |> alpine_ref("myInput"),
  htmltools::tags$button("Focus") |>
    alpine_on("click", paste0(alpine_refs("myInput"), ".focus()"))
) |>
  (\(x) htmltools::tags$div(x))() |>
  alpine_data(x = "")
