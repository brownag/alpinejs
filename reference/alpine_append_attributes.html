alpine_append_attributesR Documentation

Append attributes to an HTML tag

Description

Add HTML attributes to a tag object, preserving attribute name case. Useful for Alpine.js directives and custom JavaScript attributes that require specific casing (e.g., x-bind:textContent, ⁠@click⁠).

Usage

alpine_append_attributes(tag, ...)

Arguments

tag

An htmltools tag object.

...

Attributes to append. Can be:

  • Named arguments: ⁠tag, .attr1 = value1, .attr2 = value2⁠

  • A single named character vector: c("attr1" = "value1", "attr2" = "value2")

Details

Note: Most users should use alpine_attr() with alpine_tag() for organized directive assignment. Use this function for low-level attribute manipulation directly on tags.

Unlike htmltools::tagAppendAttributes(), this function preserves the case of attribute names. This is essential for Alpine.js directives and custom data attributes where case matters.

Difference from alpine_attr():

  • alpine_append_attributes() - Direct tag manipulation, low-level

  • alpine_attr() - High-level, for use with alpine_tag()

Value

The modified tag with attributes appended.

See Also

Other Tag Utilities: alpine_attr()

Examples


# Low-level attribute manipulation
tag <- htmltools::tags$div("Content")
tag |>
  alpine_append_attributes("x-bind:title" = "myVar", "@click" = "handleClick()")

# With high-level alpine_tag() - preferred
alpine_tag("div", "Content",
  alpine_attr(
    `x-bind:title` = "myVar",
    `@click` = "handleClick()"
  )
)
