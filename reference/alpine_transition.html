alpine_transitionR Documentation

Apply enter/leave transitions to an element

Description

Adds x-transition attributes to animate an element when it is shown or hidden via x-show. Two modes are supported: the transition helper (using modifiers for common fade/scale effects) and CSS class mode (for full control using Tailwind or custom CSS classes).

Usage

alpine_transition(
  tag,
  .duration = NULL,
  .delay = NULL,
  .opacity = FALSE,
  .scale = FALSE,
  .scale_value = NULL,
  .origin = NULL,
  .enter = NULL,
  .enter_start = NULL,
  .enter_end = NULL,
  .leave = NULL,
  .leave_start = NULL,
  .leave_end = NULL,
  .cssSelector = NULL
)

Arguments

tag

An htmltools tag object that also has x-show (via alpine_show()).

.duration

Numeric. Transition duration in milliseconds (helper mode only).

.delay

Numeric. Transition delay in milliseconds (helper mode only).

.opacity

Logical. If TRUE, apply opacity transition only (no scale). Helper mode only.

.scale

Logical. If TRUE, include a scale transition. Helper mode only.

.scale_value

Numeric 0-100. Scale percentage (e.g., 80 scales to 80%). Only used when .scale = TRUE. Helper mode only.

.origin

Character. Scale origin: "top", "bottom", "left", "right", or space-separated combinations like "top right". Only used with .scale = TRUE.

.enter

Character. CSS classes applied for the entire enter phase.

.enter_start

Character. CSS classes for the start of enter (before element appears).

.enter_end

Character. CSS classes for the end of enter (element fully visible).

.leave

Character. CSS classes applied for the entire leave phase.

.leave_start

Character. CSS classes for the start of leave.

.leave_end

Character. CSS classes for the end of leave (element hidden).

.cssSelector

Optional CSS selector for targeting a nested element.

Details

Helper mode (default, using modifiers): Applies a built-in fade + scale effect. Add modifiers to customize:

  • .opacity = TRUE: fade only (no scale)

  • .scale = TRUE: scale only (with optional .scale_value and .origin)

  • .duration = 500: 500ms transition

  • .delay = 50: 50ms delay

Helper mode produces a single x-transition[.modifier.modifier...]="" attribute.

CSS class mode (when any of .enter, .enter_start, .enter_end, .leave, .leave_start, .leave_end are provided): Attaches separate x-transition:phase="classes" attributes for each phase. This is used with utility CSS frameworks like Tailwind CSS.

You can mix both modes: use CSS class mode for enter/leave phases alongside helper mode modifiers where appropriate.

Value

The modified tag with x-transition attribute(s) appended.

Examples


# Helper mode: fade + scale, 300ms
htmltools::tags$div("Hello") |>
  alpine_show("open") |>
  alpine_transition(.duration = 300)

# Helper mode: opacity only
htmltools::tags$div("Hello") |>
  alpine_show("open") |>
  alpine_transition(.opacity = TRUE)

# CSS class mode (Tailwind)
htmltools::tags$div("Hello") |>
  alpine_show("open") |>
  alpine_transition(
    .enter       = "transition ease-out duration-300",
    .enter_start = "opacity-0 scale-90",
    .enter_end   = "opacity-100 scale-100",
    .leave       = "transition ease-in duration-300",
    .leave_start = "opacity-100 scale-100",
    .leave_end   = "opacity-0 scale-90"
  )
