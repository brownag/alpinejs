alpine_storage_getR Documentation

Get Value from localStorage

Description

Helper to create a JavaScript expression that retrieves a value from browser localStorage with an optional default fallback.

Usage

alpine_storage_get(key, default = NULL)

Arguments

key

Character string: the localStorage key to retrieve

default

Value to use if the key doesn't exist. Can be:

  • NULL (no default, returns just the getItem call)

  • Character string (quoted in JavaScript)

  • Numeric value

  • Logical value (TRUE/FALSE -> true/false)

  • A list/object (will be serialized using alpine_object())

Details

For initializing state with persisted values: 

theme: alpine_storage_get("theme", default = "light")

When using JSON objects in localStorage (as with alpine_storage_set()), parse the result: 

# Get stored settings or empty object
settings: JS("JSON.parse(localStorage.getItem('settings') || '{}')")

Value

An htmlwidgets::JS object containing a JavaScript expression that retrieves from localStorage or uses the default.

See Also

Other Client Storage: alpine_storage_set()

Examples


htmltools::tags$div(
  htmltools::tags$span() |> alpine_text("theme"),
  htmltools::tags$button("Toggle Dark") |> alpine_on("click", "theme = 'dark'"),
  htmltools::tags$button("Toggle Light") |> alpine_on("click", "theme = 'light'")
) |>
  alpine_data(
    theme = alpine_storage_get("theme", default = "light")
  )
