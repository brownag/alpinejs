alpine_effectR Documentation

Re-evaluate an expression when its dependencies change

Description

Creates an x-effect attribute containing a JavaScript expression that Alpine.js re-evaluates automatically whenever any reactive data it references changes. Similar to a watcher, but without specifying which properties to watch.

Usage

alpine_effect(tag, expression, .cssSelector = NULL)

Arguments

tag

An htmltools tag object.

expression

Character string containing a JavaScript expression. Alpine.js tracks all reactive data accessed during evaluation and re-runs the expression when any of those values change.

.cssSelector

Optional CSS selector for targeting a nested element.

Details

Useful for side effects that depend on reactive state, such as logging, analytics, or syncing to external APIs. Alpine.js runs the expression once on initialization and again whenever any referenced data changes.

For watching a specific property, use alpine_watch() via alpine_init().

Value

The modified tag with x-effect attribute appended.

See Also

Other Core Directives: alpine_bind(), alpine_cloak(), alpine_data(), alpine_data_js(), alpine_for(), alpine_html(), alpine_id(), alpine_if(), alpine_ignore(), alpine_init(), alpine_modelable(), alpine_on(), alpine_ref(), alpine_show(), alpine_teleport(), alpine_text(), alpine_transition(), alpine_when()

Examples


htmltools::tags$div(
  htmltools::tags$input(type = "text") |> alpine_model("query")
) |>
  alpine_effect("console.log('Query changed:', query)") |>
  alpine_data(query = "")
