alpine_prepare_crosstalk_dataR Documentation

Prepare Data for Crosstalk Integration

Description

Extracts and prepares R data for use with Crosstalk SharedData, handling key extraction, grouping, and JSON serialization for Alpine.js consumption.

Usage

alpine_prepare_crosstalk_data(data, key_column = NULL, group = NULL)

Arguments

data

A data.frame to prepare.

key_column

Character string naming the column to use as row identifiers for Crosstalk selection/filtering. If NULL, row numbers are used.

group

Character string naming the Crosstalk group (e.g., "iris_data"). This group name must match across all widgets that should be synchronized.

Details

Key Extraction: If key_column is specified, values from that column are used as row keys. Otherwise, row numbers (1, 2, 3, ...) are converted to characters.

Group Names: Group names should be unique, meaningful identifiers. Examples:

  • "iris_species_table"

  • "mtcars_selection"

  • "housing_data_1"

The same group name must be used across all widgets that share selections.

Value

A list containing:

  • keys: Character vector of row identifiers (Crosstalk keys)

  • data: R data structure ready for JSON serialization

  • group: The group name (passed through)

  • key_column: The name of the key column (for JS reference)

See Also

Other Crosstalk Integration: alpine_crosstalk_table(), alpine_has_crosstalk()

Examples


prepared <- alpine_prepare_crosstalk_data(
  iris,
  key_column = "Species",
  group = "iris_demo"
)
