alpine_filter_buttonsR Documentation

Alpine.js Filter/Tab Button Group Component

Description

Creates a group of buttons for filtering or selecting options. Typically used to toggle between different views or filter states. Uses alpine_on() for click events and alpine_bind() for dynamic styling of the active button.

Usage

alpine_filter_buttons(
  choices,
  state_var,
  active_style = NULL,
  inactive_style = NULL,
  button_class = NULL,
  container_class = NULL
)

Arguments

choices

A named character vector or list where names are button labels and values are the values to assign to the state variable. Example: c("All" = "", "Active" = "active", "Archived" = "archived") or list("Option 1" = "val1", "Option 2" = "val2").

state_var

Character string specifying the state variable that tracks the currently selected value. Example: "selectedFilter".

active_style

Optional character string with inline CSS for active button styling. Default applies ⁠background-color: #007bff; color: white;⁠

inactive_style

Optional character string with inline CSS for inactive button styling. Default applies lighter gray background.

button_class

Optional CSS class(es) to apply to all buttons. Useful for framework integration (e.g., Bootstrap, Tailwind).

container_class

Optional CSS class(es) for the button group container (wrapper div).

Details

The component generates a div with multiple buttons, each with:

  • An alpine_on("click", ...) handler that sets the state variable

  • An alpine_bind() that dynamically applies active/inactive styling

Styling Strategy:

  • Provide active_style for the selected button's appearance

  • Provide inactive_style for unselected buttons

  • Use button_class to add base styles (padding, border, cursor, etc.)

  • Combine with CSS frameworks for advanced styling

State Tracking: The component tracks which button is active by comparing the state variable value with each button's value. The first button matching ⁠state_var === value⁠ receives the active styling.

Value

An htmltools tag object (div) containing the button group, with each button bound to the specified state variable. Pipe-compatible.

See Also

Other UI Components: alpine_accordion(), alpine_button(), alpine_field(), alpine_modal(), alpine_stat_card(), alpine_tabs(), alpine_value_display()

Examples


alpine_filter_buttons(
  choices = c("All" = "", "Active" = "active", "Inactive" = "inactive"),
  state_var = "selectedStatus"
) |>
  alpine_data(selectedStatus = "")
