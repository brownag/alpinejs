alpine_next_tickR Documentation

Execute code after Alpine has updated the DOM

Description

Generates a ⁠$nextTick(callback)⁠ JavaScript expression that defers execution of a callback until after Alpine.js has finished processing the current reactive update cycle and updated the DOM. Useful when you need to access DOM elements or measurements after a state change.

Usage

alpine_next_tick(callback)

Arguments

callback

Character string. A JavaScript function expression to execute after the next DOM update (e.g., "() => $refs.input.focus()" or "() => doSomethingWithUpdatedDOM()").

Details

⁠$nextTick⁠ is equivalent to Vue's ⁠$nextTick⁠. When reactive data changes, Alpine.js batches DOM updates. ⁠$nextTick⁠ ensures your callback runs after the batch completes, so the DOM reflects the latest state.

Value

An htmlwidgets::JS object containing the ⁠$nextTick(...)⁠ expression.

See Also

Other Magic Properties: alpine_dispatch(), alpine_el(), alpine_refs(), alpine_store_js(), alpine_watch()

Examples


htmltools::tags$button("Focus Input") |>
  alpine_on("click", alpine_next_tick("() => $refs.myInput.focus()"))
