alpine_count_filteredR Documentation

Computed Property: Count Filtered Items

Description

Helper to create a computed property that counts items matching a condition. Returns a JavaScript function that filters a collection and returns the count.

Usage

alpine_count_filtered(property, condition)

Arguments

property

Character string: name of the array property to filter

condition

Character string: filter condition using x as the item variable

Details

This helper generates a function equivalent to: 

function() {
  return this.{property}.filter(x => {condition}).length;
}

The condition should reference the item as x. For example:

  • !x.completed – count uncompleted items

  • ⁠x.type === 'income'⁠ – count income transactions

Value

An htmlwidgets::JS object containing a JavaScript function that returns a count when called.

See Also

Other Computed Properties: alpine_combine_conditions(), alpine_compute(), alpine_multi_condition(), alpine_sum_filtered()

Examples


htmltools::tags$div() |>
  alpine_data(
    todos = list(
      list(id = 1, title = "Task 1", completed = FALSE),
      list(id = 2, title = "Task 2", completed = TRUE)
    ),
    activeTodos = alpine_count_filtered("todos", "!x.completed"),
    completedTodos = alpine_count_filtered("todos", "x.completed")
  )
