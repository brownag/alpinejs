alpine_forR Documentation

Repeat an element for each array or object item

Description

Creates an Alpine.js loop using ⁠<template>⁠ with ⁠x-for⁠ and optional x-key attributes. For each item, Alpine.js renders a copy of the template element using the iteration variables.

Usage

alpine_for(inner_tag, expression, key = NULL)

Arguments

inner_tag

An htmltools tag to repeat. This tag will be the template for each iteration.

expression

Character string containing the iteration expression (e.g., "item in items", "(value, key) in object", "(item, index) in array"). The variable(s) defined here are available inside the repeated element.

key

Optional character string specifying a unique key for each item. Example: "item.id". Keys help Alpine maintain element identity when the list changes, improving performance and state preservation. If NULL, no x-key attribute is added.

Details

Template Syntax: Alpine uses ⁠<template>⁠ tags to wrap looped content. The browser doesn't render the ⁠<template>⁠ tag itself, only the repeated content inside it.

Iteration Variables: The variable(s) in the expression are available in the scope of nested elements, but not outside the template.

Keys: Provide a key whenever your list items have a unique identifier (e.g., database ID, UUID). This allows Alpine to:

  • Match DOM elements to data items when the list reorders

  • Preserve component state and input values during updates

  • Improve performance by avoiding full re-renders

Common Patterns: 

# Array iteration
alpine_for(alpine_tag("div", alpine_tag("p") |> alpine_text("item.name")), "item in items", key = "item.id")

# Array with index
alpine_for(alpine_tag("span") |> alpine_text("index"), "(item, index) in items", key = "item.id")

# Object iteration
alpine_for(alpine_tag("div", alpine_tag("span") |> alpine_text("value")), "(value, key) in config")

Value

An htmltools ⁠<template>⁠ tag with ⁠x-for⁠ and optionally x-key attributes applied. Automatically includes the Alpine.js dependency. The template can be used within an alpine_data() component.

Examples


alpine_for(
  htmltools::tags$div(htmltools::tags$span() |> alpine_text("item.name")),
  "item in items",
  key = "item.id"
