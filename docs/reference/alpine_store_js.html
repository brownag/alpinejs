alpine_store_jsR Documentation

Access a global Alpine store value

Description

Generates a ⁠$store.name⁠ or ⁠$store.name.property⁠ JavaScript expression for reading from or writing to a global Alpine store registered with alpine_global_store(). Use the result in directives, event handlers, and expressions throughout any Alpine component on the page.

Usage

alpine_store_js(store_name, property = NULL)

Arguments

store_name

Character string. The name of the store (as passed to alpine_global_store()).

property

Optional character string. A property path within the store (e.g., "on", "theme", "user.name"). If NULL, returns the store root.

Details

Store access expressions can be used anywhere Alpine expressions are accepted:

  • In conditions: alpine_show(div, alpine_store_js("app", "isLoggedIn"))

  • In event handlers: alpine_on(btn, "click", "$store.darkMode.on = !$store.darkMode.on")

Unlike local component data, stores are globally accessible across all Alpine components on the page.

Value

An htmlwidgets::JS object containing the ⁠$store.name[.property]⁠ expression.

See Also

Other Magic Properties: alpine_dispatch(), alpine_el(), alpine_next_tick(), alpine_refs(), alpine_watch()

Examples


# Access store root
alpine_store_js("darkMode")

# Access a store property
alpine_store_js("darkMode", "on")
